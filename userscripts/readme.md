# GeoFS Legacy Userscripts

> [!CAUTION]
> **Educational And Fair-Play Disclaimer**: `GeoFS_Extension` is an open-source, client-side flight instrumentation and realism enhancement suite intended strictly for educational and single-player simulation enjoyment. It does **not** bypass GeoFS subscriptions, ad-reward entitlements, multiplayer server rules, or platform access controls.

This folder preserves the standalone Tampermonkey/Greasemonkey `.user.js` scripts for reference and manual installation if you prefer individual scripts instead of the unified Chrome extension.

Most pilots should install the unified **GeoFS Extension** instead — it bundles every feature below into one automatically synced package with cleaner controls and full support for both GeoFS V3.9 and V4.0. See the [Main README](../readme.md) to get started.

## How To Use A Standalone Userscript

1. Install a browser userscript manager such as **Tampermonkey** or **Violentmonkey**.
2. Open the [`v3.9`](v3.9/readme.md) or [`v4.0`](v4.0/readme.md) folder matching the GeoFS version you fly.
3. Click any `.user.js` file you want to use, view its **Raw** file on GitHub, and confirm installation in your userscript manager.
4. Load GeoFS and make sure you do **not** run legacy userscripts at the same time as the unified Chrome extension, or their HUD panels may overlap.
