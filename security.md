# Security Policy

## Supported Versions

Only the latest release of `GeoFS_Extension` is actively supported with security updates and compatibility patches for GeoFS V3.x and V4.x.

| Version | Supported |
| :--- | :--- |
| `0.2.x` | Yes |
| Legacy Userscripts (`userscripts/v3.9/`, `userscripts/v4.0/`) | Archived (Read-Only) |

## Reporting A Vulnerability

If you discover a security vulnerability, privilege escalation, or unintended simulator/storage exposure in `GeoFS_Extension`, please do **not** open a public issue.

Instead, report it privately through one of the following channels:

- **GitHub Security Advisories**: Open a private security advisory on `https://github.com/AMFI-Disable/GeoFS_Extension/security/advisories/new`.
- **Direct Email**: Contact `evengao6688@gmail.com` with reproduction steps, affected browser/GeoFS version, and impact details.
